# Harmonized Dataset Figures — Kerala Monsoon Project

This folder contains quality-control figures generated during the spatial harmonization of SRTM terrain data to the ERA5 reference grid.

**Study region:** 72–79°E, 7–14°N

**Reference grid:** ERA5 Gaussian grid, 25 × 25 points (approximately 0.28° resolution).

## Figures

- `dh_dx_era5scale.png` — Eastward terrain-height gradient.
- `dh_dy_era5scale.png` — Northward terrain-height gradient.
- `srtm_coverage_era5grid.png` — Valid and missing SRTM elevation cells.

These plots help verify spatial alignment, terrain-gradient patterns and missing-data coverage before combining atmospheric and geographical datasets.

The analysis focuses on the June–September 2020 southwest monsoon season.
